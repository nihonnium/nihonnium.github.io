# Personal Portfolio Website

Welcome to the repository of my personal portfolio website! 

This website showcases my background as a Computer Science student, my projects in robotics and AI, and my active leadership roles. It also includes an interactive weekly diary to track my progress.

## 🔗 Live Demo
You can view the live website here: [https://nihonnium.github.io/](https://nihonnium.github.io/)

## ✨ Features
* **About Me & Skills:** A brief introduction to my academic journey, research focus, and technical skills.
* **Featured Projects:** Details about my AI research internship, UAV patent application, and microrobotics research.
* **Interactive Production Diary:** A custom-built horizontal timeline that allows users to click and read my weekly progress notes without endless scrolling.
* **Contact Form:** A working message form connected to a Supabase database.

## 🛠️ Tech Stack
This project is built using simple and lightweight web technologies:
* **HTML5** for the structure.
* **CSS3** for styling, responsive design, and animations.
* **Vanilla JavaScript** for the interactive timeline logic.
* **Supabase (REST API)** to handle form submissions without a complex backend.
